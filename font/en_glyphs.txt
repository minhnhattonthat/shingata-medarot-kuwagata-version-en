# English glyphs for the dialogue VWF (tools/font.py; drawn for this project, MIT like the repo).
# `@XX c [advance]` starts a glyph: code XX, the character tbl/en.tbl maps to it, and the advance in px (default:
# ink width + 1). The rows that follow are the cell rows from y=5 down (y=5..13; missing rows are blank).
# `#` = ink (colour F), `+` = half ink (colour 8), `.` = background (colour 1). Cap height y5-y11, x-height y7-y11,
# descenders y12-y13. Glyphs start at x=0; nothing may be wider than 8 px.
