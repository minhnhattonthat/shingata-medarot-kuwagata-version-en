# Prior work

- **This game:** 真型メダロット カブト/クワガタバージョン (Shingata Medarot), GBA, Imagineer, developed by Rocket Company,
  2004-12-16. A remake of the 1997 Game Boy *Medarot* (the first game), with the battle system of Medarot 2 CORE.
  Japan only; no official English release. No English fan patch was found (web search 2026-11-17).
  Sources: game.watch.impress.co.jp/docs/20041021/meda.htm; dic.nicovideo.jp 真型メダロット.
- **Not this game:** *Medabots: Metabee / Rokusho* (GBA, Natsume, 2003) localises Medarot 2 CORE (a Medarot 2 remake);
  *Medabots AX* is a different action game. Both are useful sources of **official English names** for the shared
  cast and Medabots (Metabee, Rokusho, Ikki-style naming, Medaforce, Robattle, Medawatch...).
- **Earlier fan patch of the original story:** *Medarot (GB) Kabuto/Kuwagata* English patch by the Medabots
  translation group (github.com/Medabots/medarot1, built from a disassembly; also distributed as "Cash Medal Chameleon"
  release). Same story and cast as this remake: use its names for characters, parts and medals with no official
  English (decision D2). Read its text dumps when building the glossary in phase 6; don't run its binaries.
- Cast note (guess, check in phase 6): Medarot 1's hero is ヒカル (Hikaru Agata; the anime dub calls him Henry). The script
  uses ヒカル 25 times and the hero's default name in name entry is still unknown (the test runs typed ガンマ...). Fix every
  name against the medarot1 patch and the official Medabots English before writing the glossary.
